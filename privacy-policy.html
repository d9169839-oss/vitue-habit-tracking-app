3. Data Storage, Security & Third-Party Sub-Processors

  • Encryption in Transit: All communication between the App and cloud servers is encrypted via HTTPS / TLS 1.3.
  • Encryption at Rest: Cloud records are encrypted at rest using AES-256 on Google Cloud Firestore. Local records are stored in the private Android app sandbox protected by OS File-Based Encryption.
  • Strict User Isolation: Firestore Security Rules enforce cryptographic UID isolation (request.auth != null && request.auth.uid == userId) so only your authenticated session can access your records.
  • Sub-Processors: We use Google Firebase Authentication, Google Cloud Firestore, and Google Play Services Credential Manager solely as secure cloud infrastructure providers (Firebase Privacy Notice).

4. Account & Data Deletion (In-App & Web HTTPS)

You have complete control over your data and can permanently delete your account and all associated cloud and local records at any time with zero post-deletion retention period:

  • Option A — Instant In-App Deletion: Open Virtue Habit Tracker → Go to the Profile tab → Scroll down and tap Delete Account Permanently → Confirm. This immediately deletes your Firebase Auth user, all Cloud Firestore collections (habits, habitCheckIns, programEnrollments, programActivities), and wipes your local device database.
  • Option B — Web / Email Deletion Request: If you have uninstalled the App, visit our dedicated HTTPS Account Deletion Portal or email d9169839@gmail.com with the subject Account Deletion Request — Virtue Habit Tracker. Requests are completed within 7 business days.
